# Controller and touch controls

| Control | Action |
| --- | --- |
| D-pad / left stick | Move the selection; quiet rate-limited tick, no typing pulse |
| A | Activate the selected key; brief press feedback |
| B | Hide the keyboard |
| X | Delete; holding repeats |
| Y | One-time Shift; tap again to turn it off |
| Hold Y / long-press Shift | Caps Lock; tap Y/Shift to turn it off |
| L1 | Letters / symbols |
| R1 | Swap keyboard screen |
| Start | Enter / editor action |
| R3 | Space with its own sound |
| L3 | Paste through the current input connection |
| Right-stick horizontal axis | Move the editor cursor, when delivered to the IME |

L2/R2 are not bound. Controller badges use X blue, Y green, A red and B yellow. Touch uses a temporary solid highlight and a character preview, not a lingering ripple. Moving a finger outside the key cancels that touch; it does not select a neighboring key. Shift/Caps, keyboard screen switches, cancellation and held Delete use the same shared input actions as controller shortcuts.

Shift is outlined when off, filled for one-time Shift and underlined for Caps Lock. Numbers and punctuation do not clear Caps Lock. Sound follows Android's touch-sound setting/system-effects volume. No volume or audio-focus changes are requested.
