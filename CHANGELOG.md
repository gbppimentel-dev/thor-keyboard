# Changelog

## 1.0.0 — initial standalone source
- Extracted the original keyboard from Thor Tools 1.28 into package `dev.gbppimentel.thorkeyboard`.
- Added a dedicated setup activity, height control and optional minimal accessibility overlay host.
- Added an Open Wayfinder shortcut and documentation links to Wayfinder and Thor Tools.
- Retained opposite-screen routing, top split/bottom normal layouts, touch previews, controller controls, Shift/Caps and local sounds.
- Standalone package compiled/inspected locally; no standalone runtime/device verification claimed.
